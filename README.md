# CodeAlpha Data Visualization

## Project Overview
This project focuses on visualizing student performance data using Python.

## Objective
The objective is to create different visualizations to understand student marks and study hours.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
The dataset contains:
- Name
- Gender
- Age
- Study Hours
- Attendance
- Marks

## Visualizations Created
1. Bar Chart - Student Marks
2. Line Chart - Study Hours by Student
3. Scatter Plot - Study Hours vs Marks

## Output
The project generates three different charts using Matplotlib to visualize the student data.

## Files
- `visualization.py` - Python visualization program
- `student_data.csv` - Student dataset
- `README.md` - Project documentation
